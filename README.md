# 🧮 Simple Calculator

A simple and responsive calculator built using **HTML, CSS, and JavaScript**. This project is designed to demonstrate basic JavaScript functions, DOM manipulation, event handling, and simple arithmetic operations.

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* `%` Percentage
* ⌫ Delete last character
* `C` Clear display
* `=` Calculate result
* 📱 Responsive and clean UI
* 🎨 Simple calculator design

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and layout
* **JavaScript** – Calculator functionality

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/VarunVP007/Simple_Calculator.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

That's it! 🎉
